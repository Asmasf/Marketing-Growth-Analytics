# Marketing-Growth-Analytics

Overview

This project analyzes airline customer satisfaction to identify service factors that influence customer experience and loyalty.

Tools
Python
Power BI
Pandas
Key Insights
Customer Satisfaction (CSAT) remains relatively low.
Economy Class passengers report lower satisfaction.
Online Boarding has the greatest impact on customer satisfaction.
Inflight WiFi Service requires improvement.


Recommendations
Improve Online Boarding experience.
Enhance WiFi service quality.
Prioritize Economy Class improvements.
Monitor customer satisfaction regularly.
